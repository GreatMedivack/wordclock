# ПЛАН ЗАВЕРШЕНИЯ СБОРКИ

## ШАГ 5: ПАЙКА ПИТАНИЯ (после покупки проводов)

### 5.1 +5V шина (красный провод 22AWG)
```
Блок питания 5V → Row 0 левый +5V
Row 0 правый +5V → Row 1 правый +5V
Row 1 левый +5V → Row 2 левый +5V
Row 2 правый +5V → Row 3 правый +5V
Row 3 левый +5V → Row 4 левый +5V
... и так далее до Row 15
```

### 5.2 GND шина (черный провод 22AWG)
Аналогично +5V, но черными проводами

### 5.3 Инжекция питания (дополнительно, для стабильности)
- БП → Row 0 (+5V + GND) ✓ (уже в шаге 5.1)
- БП → Row 4 (+5V + GND)  
- БП → Row 8 (+5V + GND)
- БП → Row 12 (+5V + GND)

## ШАГ 6: РЕЗИСТОР И КОНДЕНСАТОР

### 6.1 Резистор 330Ω на DATA вход
```
ESP32 GPIO48 → резистор 330Ω → Row 0 DIN
```

### 6.2 Конденсатор 1000µF на питание входа
```
БП +5V ──┐
          ├─ конденсатор 1000µF ─┘
БП GND ──┘
```

## ШАГ 7: ПОДКЛЮЧЕНИЕ ESP32

### Подключение к ESP32-S3:
- **GPIO48** → резистор → DATA (Row 0 DIN)
- **GND** → общая GND шина
- **3.3V или 5V** (через USB для питания)
