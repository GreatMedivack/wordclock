# РЕКОМЕНДАЦИИ ПО СЕЧЕНИЮ ПРОВОДОВ

## 260 LED WS2812B — РАСЧЕТ ТОКОВ

### 1. ТОКОВЫЕ НАГРУЗКИ
- **1 LED макс. ток:** 60мА (белый,	full brightness)
- **260 LED:** 260 × 0.06 ≈ **15.6А** (при 100% яркости)
- **Реально при BRIGHTNESS=40 (Arduino код):** ~6.2А
- **Разумный запас:** **7-8А**

### 2. ПОДСЧЕТ НА СЕКЦИИ (4 ряда по 16 LED)
- **4 ряда = 64 LED:** 64 × 0.06 × 0.4 ≈ **1.5А**
- **Богатый запас:** **2А**

## РЕКОМЕНДУЕМЫЕ СЕЧЕНИЯ

### ДЛЯ +5V ПИТАНИЯ
```
 Requirement | AWG  | Сечение мм² | Макс ток | Примечание
-------------|------|-------------|----------|----------
 Вход питания| 18-20| 0.75-1.0    │ 5-10А    │ От БП к Row 0
 Инжекция     | 20-22| 0.5-0.75    │ 3-5А     │ К Row 4,8,12
 Шины между   | 22   │ 0.5         │ 2-3А     │ Между рядами
```

### ДЛЯ GND
- **Такие же, как +5V**

### ДЛЯ DATA
```
 Requirement | AWG  | Сечение мм² | Примечание
-------------|------|-------------|----------
 DATA линии   | 24-26| 0.2-0.25    │ Токо малый, гибкость важна
```

## ЧТО КУПИТЬ

### **ОПТИМАЛЬНЫЙ НАБОР:**
1. **Красный провод 20-22 AWG** (сечение 0.5-0.75 мм²) — метров 10
2. **Черный провод 20-22 AWG** (сечение 0.5-0.75 мм²) — метров 10  
3. **Желтый/оранжевый провод 24 AWG** (сечение 0.25 мм²) — метров 5

### **МИНИМАЛЬНЫЙ НАБОР (если найдете):**
- 22 AWG для всего — сойдет при яркости до 50%

### **УНИВЕРСАЛЬНЫЙ ВАРИАНТ:**
- **Силовой кабель (типа UTP/SFTP) 0.75 мм²** — можно разобрать на жилы
- Или **компьютерный шнур 18 AWG**

## Альтернативы, если не найдете конкретный AWG:

### Из обычных проводов:
- **Телефонный провод** (~0.5 мм²) — для +5V/GND OK
- **Сетевой провод 3×0.75 мм²** — идеально для +5V/GND
- **Аудиокабель** (внутренние жилы) — для DATA

## ТАБЛИЦА ВИЗУАЛЬНО:

```
Сечение 0.2 мм² (AWG 24) → ТОЛЬКО DATA
Сечение 0.5 мм² (AWG 22) → +5V/GND между рядами OK
Сечение 0.75 мм² (AWG 20-18) → Вход питания от БП
Сечение 1.0 мм² (AWG 18) → Избыточно, но надежно
```

## ЛУЧШИЙ ВАРИАНТ:
- **От блока питания** →_row** → **20 AWG (0.75 мм²)**
- **Между рядами** → **22 AWG (0.5 мм²)**
- **DATA** → **24 AWG (0.25 мм²)**

Так что ищите провода 20-22 AWG для питания и 24 AWG для данных!
